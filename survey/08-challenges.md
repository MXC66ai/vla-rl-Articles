# 第7章 开放挑战与未来方向

## 7.1 时序推理与闭环控制

尽管 StreamPI、MemoryVLA++ 等已显著增强 VLA 的时序能力，闭环控制在真实机器人上仍未完全解决。当前 VLA 多以开环动作块（action chunk）方式执行，缺乏对执行误差的在线感知与纠正。未来方向包括：预测-纠正双回路架构、时序因果推理（LaST₀ 的延续）、以及将时序建模与世界模型预测深度耦合。毫米级精细操作中的误差容忍度问题（Astribot 团队指出）仍是潜空间预测方法的未跨越门槛。

## 7.2 样本效率鸿沟

VLA 训练依赖数十万至百万级演示，技能 RL 虽将 RL 的样本需求降低数倍，但技能库的构建本身仍需大量数据。样本效率的终极瓶颈在于"机器人数据稀缺"。三条突围路径正在成形：人类视频规模化利用（mimic-video、Robot Self-Improvement）、世界模型想象训练（ProphRL）、以及基础模型跨本体数据共享（Qwen-VLA）。三者若能贯通——以人类视频构建技能库、以世界模型提供练习场、以共享表征跨本体复用——样本效率有望实现数量级突破。

## 7.3 跨本体迁移

跨本体迁移的现状是"可用但不可靠"：同构本体间迁移已较成熟，异构本体（如四足→双臂人形）迁移仍需任务特定适配。深层障碍在于动作表征的本体耦合性：关节空间的动作指令无法直接跨本体使用。未来方向包括：本体无关的动作表征（如末端效应器空间、任务空间）、统一视觉-运动编码的扩展（XR-1 方向）、以及"通用技能 + 本体适配层"的两段式架构。

## 7.4 安全与对齐

VLA × RL 融合带来了安全维度的新挑战。VLA 的语义先验可能包含有害或危险的行为模式；RL 的探索可能越过安全边界；世界模型的想象可能在安全评估中产生假阳性（把危险行为误判为安全）。对齐方向包括：基于技能的约束策略（将行为约束在已验证的技能库内）、人类反馈的在线对齐（FlowDAgger 方向）、以及世界模型不确定性校准（在低置信区域拒绝决策）。安全性与性能的联合优化——而非事后补救——应成为下一代系统的设计原则。

## 7.5 奖励工程与信用分配

奖励设计始终是 RL 的软肋。LLM 驱动的奖励塑形（Master Skill Learning）与 VLM 奖励器（RL-VLM-F）缓解了人工设计的负担，但奖励黑客与奖励偏置问题仍未根除。技能级信用分配（在技能粒度而非时间步粒度上分配奖励）是缓解稀疏奖励的有效途径，但其理论基础（如何定义最优技能边界）尚不完善。

## 7.6 硬件-算法协同设计

VLA 的能力上限正日益受限于硬件：推理延迟受算力约束，灵巧操作受执行器精度约束，真机部署受成本约束。Dexora 的工作表明，硬件-算法协同设计（36 自由度硬件 + 对应 VLA 架构）能够解锁此前不可行的能力。未来方向包括：面向边端部署的 VLA 架构搜索、执行器特性感知的策略学习、以及"虚拟-真实"数字孪生训练。

## 7.7 开放生态与标准化

领域的长期发展依赖开放生态：开源模型（OpenVLA、π₀.5、Dexora、RynnVLA-001）、开源平台（FluxVLA Engine、Isaac Lab）、统一评估协议（第6章建议）。标准化将降低复现成本、加速方法对比，但也需警惕"指标过拟合"——过度优化单一基准而牺牲真实泛化。

## 本章小结

本章讨论了时序闭环、样本效率、跨本体、安全对齐、奖励工程、硬件协同与开放生态七大类开放挑战。这些挑战相互交织：样本效率依赖人类视频与世界模型，而后者又依赖时序与安全的可靠性。未来的突破更可能来自系统性组合（如"人类视频技能库 + 世界模型练习 + 安全约束 RL"）而非单一算法的孤立改进。

## 7.8 未来方向路线图

基于上述分析，本文给出三条未来研究路线：

**路线A（数据驱动）**：人类视频 → 技能蒸馏 → 跨本体迁移。核心问题：如何从异构、无标注的人类视频中提取本体无关的通用技能。

**路线B（练习驱动）**：世界模型 → 想象训练 → 真机微调。核心问题：如何保证想象训练的真实性（不确定性校准、闭环校正）。

**路线C（学习驱动）**：VLA 先验 → 技能约束 → 持续强化。核心问题：如何在保留语义泛化的同时实现零成本在线改进。

三条路线并非互斥，其交汇处——"以人类视频构建技能、以世界模型练习、以安全约束持续强化"——最有可能诞生下一代加速机器人学习系统。
