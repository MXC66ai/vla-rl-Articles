# 第5章 VLA × RL 交叉融合

## 5.1 融合动机

前两章分别刻画了 VLA 模型与技能强化学习两条研究主线。本章论证一个核心论点：二者的融合并非研究者的刻意撮合，而是能力互补的必然结果。

VLA 模型的优势在于语义泛化：借助互联网规模预训练，VLA 能够理解开放世界指令、识别未见物体、输出合理动作。但其根本缺陷在于缺乏闭环改进机制——VLA 以行为克隆方式训练，只能复现训练数据中的行为模式，无法从自身试错中学习，也无法超越示范质量。与此相对，强化学习天然具备改进机制，但其从零学习的样本效率使真机训练几乎不可行。

因此，最自然的融合方式呼之欲出：**以 VLA 提供策略先验与语义理解，以 RL 提供闭环改进，以技能提供结构压缩，以世界模型提供练习场**。本章将融合范式归纳为三种，逐一剖析，并通过典型案例说明其工程可行性。

## 5.2 范式一：VLA 作为 RL 先验

### 5.2.1 思想

范式一的核心思想是：将预训练 VLA 策略作为 RL 的初始化或约束条件，而非从随机初始化开始学习。VLA 先验带来了三重收益：行为下限（初始策略已具备一定成功率）、语义导向（探索被引导至语言指令相关的行为区域）、表征复用（视觉-语言特征可直接用于价值估计）。

### 5.2.2 初始化式融合

最简单的融合形式：用 VLA 权重初始化策略网络，再以 RL 微调。此时 RL 只需学习 VLA 行为的"修正量"，样本需求大幅下降。该方案的技术难点在于 VLA 输出空间（动作分布）与 RL 策略空间的对接，以及微调过程中的灾难性遗忘。

### 5.2.3 约束式融合

更精细的融合将 VLA 作为约束条件而非初始化：在 RL 目标中加入"与 VLA 行为一致性"的正则项，使策略在探索的同时不偏离 VLA 先验过远。此类方法的典型实现是 KL 正则化或行为克隆辅助损失。约束式融合的优势在于可控性——可以显式调节先验约束的强度，在探索自由与安全下限之间取得平衡。

### 5.2.4 VLA 作为奖励器

VLA 的另一种先验形式是作为奖励函数：由 VLM/VLA 从视觉观测判断任务成功与否，为 RL 提供稠密或稀疏奖励。RL-VLM-F 等早期工作确立了该方向，其优点是不需要人工设计奖励，缺点是需要处理 VLM 判断的不确定性与偏置。

## 5.3 范式二：RL 作为 VLA 微调手段

### 5.3.1 思想

范式二是范式一的对偶视角：将 RL 视为 VLA 的微调算法，替代或补充行为克隆阶段。其动机在于：行为克隆只能复现演示数据，而 RL 微调能够让 VLA 在环境反馈中自主改进，突破示范质量上限。

### 5.3.2 在线 RL 微调

在 VLA 预训练后，直接以在线 RL（如 GRPO、PPO）微调策略。该路线的工程挑战在于：VLA 参数量巨大，全参数 RL 微调的计算与内存开销极高；真机交互成本昂贵；奖励信号稀疏。GRPO 因无需价值网络而成为首选优化器，显著降低了内存开销。SkillRL 即以 GRPO 对 Qwen2.5-7B 进行微调，验证了 VLA 级模型的 RL 微调可行性。

### 5.3.3 推理期微调

Act While Waiting 提出推理期微调（inference-time finetuning）：在 VLA 每次推理的等待间隙执行轻量级价值更新。这一思路将 RL 微调从"训练阶段"扩展到"部署阶段"，使 VLA 在真实任务执行过程中持续改进。其工程意义重大：不增加任何墙钟时间，即可实现真机在线学习。

### 5.3.4 微调中的灾难性遗忘

RL 微调 VLA 的核心风险是灾难性遗忘——策略过度适应新任务奖励而丧失原始语义泛化能力。缓解手段包括：低秩适配（LoRA 类方法冻结主干、只更新低秩增量）、经验回放（保留预训练数据混合训练）、以及技能库约束（将技能先验作为正则项）。目前这些手段多处于工程实践层面，缺乏系统的理论分析。

## 5.4 范式三：世界模型作为桥梁

### 5.4.1 思想

范式三通过世界模型将 VLA 与 RL 的连接从"交互式试错"升级为"想象式练习"。其核心流程为：训练一个世界模型 $W(s'|s,a)$ 近似环境动态 → VLA 策略在世界模型的想象 rollout 中接受 RL 训练 → 无需真机交互即可产生海量练习信号。

### 5.4.2 世界模型即模拟器

ProphRL 是范式三的代表作：训练"预言家"（Prophet）世界模型作为可微模拟器，VLA 在其中进行在线 RL 微调。该方案的优势在于：想象 rollout 成本远低于真机交互；梯度可穿过世界模型反向传播到策略；世界模型可复用服务于多个下游任务。ProphRL 在 AgiBot、DROID、LIBERO、BRIDGE 等基准上为不同规模的 VLA（0.5B–7B）带来 5–17% 的成功率提升，并在真机实验中取得 24–30% 的提升。

### 5.4.3 世界模型与技能的结合

世界模型与技能的结合开辟了更丰富的设计空间：在世界模型中规划技能序列（技能级想象）、在世界模型中评估技能价值（技能级价值估计）、甚至在世界模型中进化技能库。这一方向处于早期探索阶段，但逻辑上高度自洽——技能压缩时序、世界模型压缩环境，二者共同将"长时程、高维"的机器人学习问题转化为可处理的规模。

### 5.4.4 世界模型的可靠性质疑

范式三的瓶颈在于世界模型的精度：想象 rollout 中的模型误差会随轨迹长度累积，导致策略在想象中"自欺欺人"。缓解方向包括：模型不确定性校准（在低置信想象区域降低学习率）、短时程想象（以技能为单位控制想象长度）、以及真机-想象混合训练（定期用真机数据校正世界模型）。

## 5.5 典型案例深度分析

### 5.5.1 案例一：ProphRL——世界模型驱动的 VLA 强化

ProphRL 的技术路线可概括为"VLA + 世界模型 + 在线 RL"三模块协作。世界模型（Prophet）在离线数据上训练，学习状态-动作到下一状态的映射；VLA 策略在世界模型上执行 rollout 产生想象轨迹；RL 优化器（PPO/GRPO）根据想象轨迹的奖励更新 VLA。实验数据显示，该框架对不同规模的 VLA 均有效，且增益随模型规模增大而保持稳定。真机实验中 24–30% 的成功率提升验证了想象训练向真实环境的迁移能力。ProphRL 的成功为范式三提供了最强证据，其模型无关特性（可对接 VLA-adapter-0.5B、π₀.5-3B、OpenVLA-OFT-7B）更增强了普适性。

### 5.5.2 案例二：SkillRL——技能增强的 LLM/VLA 强化

SkillRL 虽以 LLM（而非完整 VLA）为研究对象，其框架可直接推广至 VLA。其核心贡献在于证明：在 RL 微调中加入技能检索与递归进化，可带来超越纯 RL 的增益。在 ALFWorld 上 12.3% 的绝对提升（与 GRPO 同优化器对比）排除了算法差异的干扰，将增益直接归因于技能机制。这一结论对 VLA × RL 融合具有直接指导意义：**VLA 强化微调应配备技能库**。

### 5.5.3 案例三：Act While Waiting——部署期持续学习

Act While Waiting 的"延迟利用"思想为融合范式提供了工程化的落地路径：VLA 在真机部署时天然存在推理延迟，将该空闲时间用于轻量级价值更新，即可在不打断任务执行的前提下实现持续强化。该方案与范式二（RL 微调 VLA）正交，可以叠加使用——推理期微调提供持续学习通道，世界模型提供额外练习数据，技能库提供结构约束。

### 5.5.4 三个案例的互补性

三个案例分别展示了融合的三个侧面：ProphRL 解决"练习场"问题（世界模型），SkillRL 解决"结构"问题（技能库），Act While Waiting 解决"时间"问题（延迟利用）。三者正交且可组合，共同构成"语义先验-技能结构-想象练习-持续学习"的完整技术拼图。

## 5.6 融合范式的统一视图

### 5.6.1 统一框架

将三种范式纳入统一框架：VLA 提供策略本体与语义先验（范式一），RL 提供改进机制（范式二），世界模型提供低成本练习场（范式三），技能库提供结构压缩与复用。四者关系可表述为：

$$\text{加速机器人学习} = \underbrace{\text{VLA 先验}}_{\text{语义}} + \underbrace{\text{技能结构}}_{\text{压缩}} + \underbrace{\text{RL 改进}}_{\text{闭环}} + \underbrace{\text{世界模型}}_{\text{练习场}}$$

### 5.6.2 设计原则

从融合实践中提炼四条设计原则：

（1）先验要"软"。VLA 先验应以约束或初始化形式引入，保留 RL 的探索自由度，而非硬性锁死策略。

（2）结构要"活"。技能库应支持递归进化，与策略协同更新，避免静态化。

（3）练习要"准"。世界模型的想象 rollout 应限定在模型高置信区域，避免误差累积。

（4）学习要"零成本"。尽可能利用现有资源（推理延迟、离线数据、人类视频）获取学习信号。

## 本章小结

本章论证了 VLA 与 RL 融合的必然性与可行性，系统阐述了三种融合范式及其组合方式。ProphRL、SkillRL、Act While Waiting 三个案例分别验证了世界模型、技能结构、延迟利用三条路径的有效性。融合的统一框架"语义先验-技能结构-强化微调-世界模型"为加速机器人学习提供了清晰的工程蓝图。第6章将转向评估维度，讨论如何公平地衡量这些方法的性能。
