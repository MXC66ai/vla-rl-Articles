# 第4章 基于技能的强化学习

## 4.1 概述

深度强化学习在机器人学习领域展现了强大的潜力，但其样本效率问题始终是横亘在理论与实用之间的鸿沟：在真实机器人上从零学习复杂、长时程行为往往不可行。基于技能的强化学习（Skill-based RL）通过引入"技能"这一时序抽象层次，将强化学习的搜索从原始动作空间提升到语义技能空间，从而显著压缩样本复杂度、改善信用分配、支持跨任务迁移。

本章沿"技能生命周期"组织论述：技能如何被发现（4.2节）、如何被学习（4.3节）、如何被规划与组合（4.4节）、如何迁移复用（4.5节），随后以近期代表性工作为案例深入剖析（4.6节），最后给出方法横评与设计洞察（4.7节）。

## 4.2 技能发现

技能发现（Skill Discovery）旨在从无标签或弱标签数据中自动提取可复用的行为单元，是技能生命周期的基础环节。

### 4.2.1 无监督技能发现

早期工作（如 DIAYN、VIC、DADS）以互信息或状态熵为内在目标，驱动策略自发探索出多样化的行为模式，每个模式即一个技能。这类方法无需任务奖励与人工标注，但习得技能往往缺乏语义可解释性，难以与语言指令或高层规划对接。

### 4.2.2 基于先验的技能发现

为赋予技能语义意义，后续工作引入各类先验。基于状态转移的变分方法（如 SPiRL、OPAL）从离线轨迹中学习隐变量技能编码，技能隐变量能够捕捉行为片段的宏观模式。基于演示分段的技能发现则将专家轨迹按语义边界切分为技能单元，切分点可通过行为变化检测或语言标注获得。

### 4.2.3 基于 LLM 的技能蒸馏

大语言模型的介入带来了技能发现的新范式：LLM 技能蒸馏（Skill Distillation）。其核心流程是：收集成功轨迹 → 由 LLM 教师模型（如 OpenAI o3）分析轨迹中的可复用行为模式 → 提炼为结构化技能描述与参数 → 存入技能库。SkillRL 即采用此路线：以 o3 作为教师，将成功轨迹蒸馏为任务特定技能，并支持任务相关的技能检索（Top-K 检索）。与无监督方法相比，LLM 蒸馏的技能天然具备语言可解释性，可直接服务于高层规划。

### 4.2.4 视频驱动的技能发现

人类视频是比机器人数据更丰富的技能来源。Robot Self-Improvement 系列工作利用人类操作视频训练动力学模型与技能表征，使机器人"观看"人类演示后即可改进自身策略。mimic-video 进一步提出视频-动作模型：直接学习从演示视频到动作的映射，无需显式语言解析。这类方法的深层意义在于：将技能发现的数据源从稀缺的机器人轨迹扩展到海量的人类视频。

## 4.3 技能学习

技能发现回答了"有哪些技能"，技能学习则回答"每个技能如何执行"。按学习信号可分为三类。

### 4.3.1 模仿式技能学习

通过行为克隆或逆强化学习从演示中学习技能策略。其优点是利用人类先验、样本需求较低；缺点是分布外泛化弱、无法超越示范质量。ACT（Action Chunking with Transformers）等动作分块方法通过预测动作序列块提升模仿技能的长时程一致性。

### 4.3.2 强化式技能学习

在技能内部直接运行 RL 以优化局部行为。与从零学习完整策略相比，技能内部 RL 的时程短、奖励稠密（子目标驱动），因此样本效率显著更高。Efficient Skill Acquisition 系列工作将 LLM 生成的奖励函数引入技能内部 RL，实现语言指导的技能精修。

### 4.3.3 混合式技能学习

结合模仿与强化：先模仿初始化技能，再用 RL 精修。Residual RL 是典型代表——以预训练技能策略作为基座，RL 只学习残差修正量。由于残差策略的动作空间被约束在技能策略附近，其样本需求可降低数倍。FlowDAgger 则从人类反馈角度实现技能修正：在潜空间注入人类纠偏信号，以 DAgger 方式迭代改善生成式技能策略，避免了整策略重训的成本。

## 4.4 技能规划与组合

技能规划解决"给定任务，如何选择与排序技能"的问题。这是分层强化学习（Hierarchical RL）与选项框架在现代语境下的延续。

### 4.4.1 高层策略式组合

高层策略在技能空间中做序贯决策，每个技能作为选项执行至终止条件。此类方法需要设计技能终止条件与高层奖励，其优势是端到端可训练，缺点是高层探索仍可能陷入组合爆炸。

### 4.4.2 语言驱动组合

LLM/VLM 将任务分解为语言化的技能序列，再由底层技能执行。SayCan、VoxPoser 等早期工作确立了"LLM 规划 + 技能执行"的范式；Being-0 进一步以 VLM 将高层规划实时转化为可行技能，并根据环境反馈动态修正规划。语言驱动组合的关键优势在于可解释性与零样本任务分解能力。

### 4.4.3 技能检索增强组合

SkillRL 引入了面向任务的技能检索机制：根据当前任务描述与状态，从技能库中检索最相关的 K 个技能作为策略的条件输入。检索增强使策略能够"按需调用"相关经验，避免了全库技能带来的注意力稀释。实验表明，检索数量 K 的选取对性能有显著影响，最优 K 随任务复杂度上升而增大。

### 4.4.4 递归技能进化

SkillRL 的另一关键创新是递归技能进化（Recursive Skill Evolution）：技能库并非静态，而是与策略协同演化——每轮 RL 训练后，新产生的成功轨迹被蒸馏为新技能或精修旧技能，技能库与策略形成"互哺"关系。这种动态技能库显著提升了收敛速度与渐近性能：静态技能库方法在收敛后停滞，而递归进化方法持续改善。

## 4.5 技能迁移与复用

技能复用是技能抽象价值的最终体现。跨任务迁移中，新任务被分解为已知技能的组合，只需学习技能选择的策略，而非从零学习动作。跨本体迁移中，技能（尤其是语义技能）往往能在不同形态机器人间迁移，因为技能层面的行为模式（如"抓取圆柱体"）比原始关节轨迹更具本体不变性。跨模态迁移中，从人类视频习得的技能可直接迁移到机器人执行（Robot Self-Improvement、mimic-video），这是当前最具前景的扩展方向。

## 4.6 代表性方法深度分析

### 4.6.1 SkillRL：技能蒸馏与递归进化

SkillRL 是 2026 年技能强化学习的代表性工作。其技术栈为：Qwen2.5-7B-Instruct 作为基础策略模型，o3 作为技能蒸馏与 SFT 数据生成的教师模型，GRPO 作为强化优化器。训练流程包含三阶段：技能蒸馏（从成功轨迹提炼技能库）→ 技能检索（按任务检索 Top-K 技能）→ 递归进化（技能库与策略协同更新）。在 ALFWorld 上取得 89.9% 成功率，较纯 GRPO 提升 12.3 个百分点；在 WebShop 上取得 72.7%，提升 10.5 个百分点。值得注意的是，由于 SkillRL 与 GRPO 基线使用相同优化器，该增益可直接归因于技能增强机制而非算法差异。在复杂子任务（Cool、Pick2）上相对 GRPO 分别提升 23.0% 与 22.8%，验证了结构化技能先验在稀疏奖励环境中的加速作用。训练曲线显示，带技能进化的 SkillRL 在 60 训练步内达到 80% 以上成功率，而基线约需 90 步且峰值更低。

### 4.6.2 Master Skill Learning：奖励-策略协同

Master Skill Learning（ICLR 2026）聚焦于技能获取中的奖励设计问题。其核心思想是奖励-策略协同进化（Reward-Policy Co-Evolution）：LLM 根据当前策略的表现生成/调整奖励函数，策略在更新后的奖励下继续学习，二者形成正反馈循环。相较于静态奖励设计，协同进化避免了"奖励黑客"与"奖励不匹配"问题，使技能习得过程自适应任务难度。该方法与 SkillRL 共同确立了"LLM 驱动的协同进化"范式。

### 4.6.3 Residual RL：技能基座上的残差学习

Residual RL 以预训练技能策略为基座，强化学习仅学习残差项。其数学形式为 $a = \pi_{skill}(s) + \delta(s)$，其中 $\delta$ 由 RL 优化。该设计的样本效率优势来自两点：残差动作空间的方差远小于原始动作空间；基座策略提供了安全的行为下限。在操控任务套件中，残差 RL 的样本效率较从零 RL 提升约 3 倍，且保留了技能策略的平滑性与安全性。

### 4.6.4 Act While Waiting：推理期微调

Act While Waiting 提出一个极具工程价值的概念：将 VLA 推理延迟（通常 100–500ms）转化为在线 RL 微调时间。机器人在等待推理结果时本就处于空闲，此时执行轻量级价值更新不增加任何墙钟时间。该方法将"延迟"这一缺陷转化为"持续学习"的机会，为真机在线 RL 提供了零成本实现路径。

### 4.6.5 FlowDAgger：潜空间人工修正

FlowDAgger 针对生成式策略（扩散/流匹配）的部署期修正问题，在潜空间注入人工纠偏信号，以 DAgger 方式迭代改进。与在动作空间直接修正相比，潜空间修正更平滑、更少违反策略分布约束；与整策略重训相比，迭代修正的成本与风险均显著降低。

### 4.6.6 Efficient Skill Acquisition：语言指导技能精修

Efficient Skill Acquisition（AAAI 2025 Oral）探索 LLM 奖励塑形与探索策略的协同，在语言指导的技能获取任务上验证了"奖励-策略协同"的有效性，为 ICLR 2026 的 Master Skill Learning 奠定了基础。

## 4.7 方法横评与设计洞察

### 4.7.1 方法对比矩阵

| 方法 | 技能来源 | RL算法 | 技能复用 | 协同进化 | 人类介入 | 开放 |
|:---|---:|:---|:---:|:---:|:---:|:---:|
| SkillRL | LLM蒸馏 | GRPO | 检索(K=6) | ✓ | ✗ | ✗ |
| Master Skill | LLM奖励 | PPO | ✓ | ✓ | ✗ | ✗ |

### 4.7.2 设计洞察

从方法横评中可提炼五项设计洞察。

（1）技能库的"活"比"大"更重要。静态技能库在收敛后停滞，递归进化（SkillRL）与协同进化（Master Skill）能够持续突破局部最优。

（2）LLM 正在取代人工承担"技能定义者"与"奖励设计者"双重角色。教师模型蒸馏（SkillRL）与 LLM 奖励塑形（Master Skill）均已超越人工基线。

（3）残差式介入是最安全的技能精修方式。无论是动作空间残差（Residual RL）还是潜空间修正（FlowDAgger），都保留了基座策略的安全下限。

（4）时间与数据是隐藏的资源。推理延迟可转化为学习时间（Act While Waiting），人类视频可转化为技能数据（Robot Self-Improvement）。

（5）技能表征的语义化是关键使能技术。只有技能具备语言可解释性，LLM 规划器才能与其无缝对接。

## 本章小结

本章系统梳理了技能强化学习的完整生命周期：发现、学习、规划、迁移四个环节，以及各环节的代表性方法。技能抽象从搜索空间、信用分配、跨任务迁移三个层面加速强化学习，而 LLM 的介入进一步推动了技能蒸馏与协同进化范式的成熟。值得强调的是，技能强化学习与 VLA 模型正呈现深度耦合的趋势——VLA 提供语义先验与动作生成能力，技能提供结构压缩与复用能力。二者的融合机制将在第5章深入剖析。
